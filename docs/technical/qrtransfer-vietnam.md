# QRtransfer Vietnam experimental extension

Original optical transport remains Decimen v3 (AGPL-3.0-or-later). Original authors and notices retained. Base27 Studio wraps arbitrary bytes reversibly into three digits per byte; this is deliberately inefficient and is not a performance claim. It uses alphabet space + A–Z and maps each digit to three balanced trits. The optional envelope includes original name, size, MIME metadata and SHA-256; the recovered download uses a safe generic MIME. The core optical sender/receiver is unchanged. CVNSS4.0 audit-safe is a separate Vietnamese text analysis tool, never a destructive transform of arbitrary files. Studio limit 16 MiB, optical transport limit 64 MiB. No new network requests required for the lab after PWA precache. Physical camera tests, browser compatibility and new performance measurements remain outstanding.
